# dsh-cmd-send v0.1.3

Date: 2026-08-20

首个通过正式发布流程发布的版本. 让 dsh web 界面支持 Cmd+Enter 发送消息, 解决长输入时误触发送的问题.

## Highlights

- 新增 "Cmd+Enter 发送" 键位: Enter 只换行, Cmd/Ctrl+Enter 排队发送, Shift+Cmd/Ctrl+Enter 插话发送.
- 忙碌时不改变 dsh 既有语义: Cmd+Enter 插入排队, Shift+Cmd+Enter 打断当前回合立即处理; 空闲时两者都直接发送.
- 中文输入法组合输入不受影响, 确认候选词的 Enter 不会误发送.
- 默认保持 dsh 内置键位 (Enter 发送), 在 设置 -> 常规 -> 发送快捷键 一键切换.

## Upgrade Notes

1. 通过 `dsh plugin --profile web add https://github.com/azazo1/dsh-cmd-send/archive/refs/tags/v0.1.3.tar.gz` 安装后重启 dsh web 并刷新页面.
2. 在 设置 -> 常规 -> 发送快捷键 中切换到 **Cmd+Enter 发送** 以启用新键位.

## Features

- 客户端: 在 composer 输入区挂载隐身键盘控制器, 于 document 捕获阶段拦截 Enter 并映射到发送/插话/换行, 未开启时完全放行内置逻辑.
- 持久化: 发送模式偏好经 Host settings 服务写入 `dsh-cmd-send.sendMode`, 重启不丢失.
- 发布流: 新增 GitHub Actions 工作流, tag push 自动构建校验并创建 release, 产物含完整 lib 与类型声明.

## Bug Fixes

- 将构建产物 (lib) 纳入版本控制, 修复 GitHub archive 安装后缺少 client bundle 无法加载的问题.
- 同步 package.json 与 dsh.plugin.json 版本号, 保证插件清单与发布版本一致.
